## Cyber Strategy Framework 🛡️

Sebuah perangkat bantu berbasis peramban (*browser-based tool*) gratis yang dirancang khusus untuk para pemimpin keamanan siber (CISO, Security Directors, & Managers) guna membangun rencana strategis, memetakan pemangku kepentingan, memprioritaskan inisiatif, menyusun kebijakan, dan menghasilkan ringkasan eksekutif siap presentasi.

---

## ✨ Fitur & Modul
Aplikasi ini dilengkapi dengan modul-modul esensial untuk kebutuhan tata kelola dan strategi keamanan siber:

| Modul | Fungsi |
| :--- | :--- |
| 📅 **Rencana Kerja 90 Hari** | Menyusun taktik 90 hari pertama berdasarkan fase transisi melintasi 4 pilar utama: *People, Process, Technology,* dan *Governance*. |
| 👥 **Matriks Pemangku Kepentingan** | Memetakan stakeholder kunci berdasarkan tingkat pengaruh (*Power*) dan kepentingan (*Interest*) ke dalam visualisasi Matriks 2x2 (*Key Players, Keep Satisfied, Keep Informed, Minimal Effort*). |
| 🗺️ **Peta Jalan & Analisis SWOT** | Mengelola prioritas proyek pengamanan siber per kuartal (Q1-Q4) dan diperkuat dengan analisis kekuatan, kelemahan, peluang, serta ancaman eksternal. |
| 📜 **Pembuat Kebijakan (Policy Builder)** | Menghasilkan draf dokumen kebijakan tata kelola terstruktur secara instan dengan 6 komponen templat profesional yang dapat disunting langsung. |
| 📊 **Ringkasan Eksekutif** | Mengonsolidasikan seluruh data dari modul-modul di atas menjadi satu laporan final terpadu dan mengekspornya ke format **PDF bersih secara lokal** (*client-side*). |

---

## 🔍 Templat Kebijakan Profesional yang Disertakan
Draf kebijakan dibuat mengacu pada standar tata kelola keamanan informasi global (seperti ISO 27001, NIST, dan UU Perlindungan Data Pribadi / PDP):
1. 🔎 **Manajemen Kerentanan:** Regulasi pemindaian otomatis dan batas waktu *patching* (mitigasi celah kritis).
2. ☁️ **Keamanan Cloud:** Manajemen identitas akses (IAM), enkripsi data, dan postur keamanan multi-cloud.
3. 🤖 **Keamanan AI & LLM:** Aturan pembatasan input data rahasia korporat pada model kecerdasan buatan publik.
4. 🔑 **Kontrol Akses:** Postur arsitektur *Zero Trust*, kewajiban Multi-Factor Authentication (MFA), dan aturan sandi.
5. 🚨 **Respons Insiden Siber:** Struktur tim CSIRT, klasifikasi tingkat keparahan insiden, dan SLA pelaporan otoritas.
6. 🗄️ **Klasifikasi Data & PDP:** Kategorisasi data (*Highly Confidential* hingga *Public*) serta kewajiban masking data pribadi.

---

> **Catatan :** Perangkat bantu ini adalah generator strategi dan kebijakan berbasis teks. Pengguna bertanggung jawab penuh untuk mengkaji dan menyesuaikan hasil draf kebijakan dengan regulasi hukum spesifik yang berlaku di wilayah hukum organisasi masing-masing.
